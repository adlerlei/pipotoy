Paper color 紙張顏色

Fill in any Pipo color token — like mibble, wibble, or glorix — and the sticky note takes on that hue. The classic sticky-note yellow (blonko) is the default, so you can omit color entirely for that nostalgic feel. Type a name that doesn't exist and it quietly falls back to blonko.

填一個 Pipo 色系 token——像 mibble、wibble、glorix——便利貼就換上那個顏色。經典的便利貼黃（blonko）是預設，所以你想走懷舊風直接不填 color 也可以。填了不存在的名字也不會壞，會安靜退回 blonko。

<pipo-stick color="mibble">綠綠的便利貼。</pipo-stick>

tilt Default 預設 自動 ±0.5~1.5°Options 選項 "off"

Turn off the lean 關掉歪斜

By default every note tilts a little — the angle is hashed from its color, so notes with different colors lean different ways (a tiny bit chaotic, in a friendly way). Add tilt="off" when you want it perfectly upright: a centered notice, a quote that should feel formal, a card on a structured grid.

預設每張便利貼都會歪一點——角度是從 color 名稱雜湊出來的，所以不同顏色會往不同方向歪（有點亂，但亂得可愛）。加上 tilt="off" 就會完全正立：拿來放公告、正式引言、整齊排列的格子都適合。

<pipo-stick color="wibble" tilt="off">端端正正一張。</pipo-stick>

pin Default 預設 無（不顯示圖釘）Options 選項 boolean attribute

Pin it on the board 釘在布告欄

Add pin (no value needed — it's a boolean attribute) and a small dark-gray dot appears on top of the note, like a real pushpin. The pin sits centered on top, so the note still tilts underneath. Perfect for bulletin-board layouts.

加上 pin（不用填值，這是 boolean 屬性），便利貼頂部就會冒出一顆深灰小圓點，像真的圖釘。圖釘固定在正中間，下面的便利貼照樣歪。布告欄風格超適合。

<pipo-stick color="mibble" pin>釘起來的便條。</pipo-stick>

Built-in · 內建行為

They hop on hover. Always.

滑過去會跳起來，永遠。

↺
The lean flips the other way
Hover a note and it lifts up while rotating the opposite direction — a note leaning left spins a touch right, then settles back when the cursor leaves. It's a tiny spring-loaded gesture that makes a wall of notes feel alive.
滑過一張便利貼，它會浮起來、同時往另一邊微微轉回去——本來歪左的會往右回一點，滑鼠離開又會彈回原位。這個小彈簧動作讓一面便利貼牆感覺活生生的。
🎨
Same color, same lean — forever
The default angle for each note is hashed from its color name, not randomized per render. So a blonko note will always tilt the same direction, even after reloading — a stable quirk, not a dice roll.
每張便利貼的預設角度是從 color 名稱雜湊出來的，不會每次重新算。所以 blonko 永遠往同一邊歪，重新整理也是——這是穩定的小怪癖，不是骰子。
🧷
Pin or no pin, the hover still works
Whether or not you add pin, every note still hops on hover. The pin sits on top and the note below still lifts — they share the stage without getting in each other's way.
不管有沒有 pin，每張便利貼 hover 都會跳。圖釘坐在頂部，下面的便利貼照樣浮起來——同台不打架。
