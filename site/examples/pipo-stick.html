Show all 4 attributes查看全部屬性
color

Paper color
Any Pipo color; default blonko

便利貼顏色；任一 Pipo 色名，預設 blonko。
size

Whole note size
mini / small / regular / big; default regular

整張便利貼大小；四個級距，預設 regular。
tilt

Natural lean
Use off to straighten; default on

預設會依顏色產生固定歪斜；設為 off 即正立。
pin

Top pin
Boolean; add it to show

顯示頂部圖釘；加入屬性即可啟用。
