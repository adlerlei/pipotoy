Layout · 版面

Shape your world.

決定你的世界長什麼形狀。

Content width 內容寬度

How wide your content area is. full stretches edge to edge; narrow keeps things cozy in the middle. On tablets and phones, everything becomes full width automatically.

內容區有多寬。full 是滿版,narrow 是窄窄地待在中間。在平板和手機上會自動變成滿版,你不用管。

<pipo-world size="medium">
  ...
</pipo-world>

Minimum height 最小高度

screen makes your world at least as tall as the browser window (100vh), so short pages never look half-empty. none lets it shrink to fit the content.

screen 讓你的世界至少和瀏覽器視窗一樣高(100vh),內容很少時頁面也不會看起來空空的。none 則是內容多高就多高。

middle Default 預設 false(關)Options 選項 true(開)/ false(關)

Vertical centering 垂直置中

Floats your content to the vertical center of the world. Perfect for login pages, error pages, or anything with one single focus. Regular pages don't need it.

讓內容浮在世界的垂直正中央。適合登入頁、錯誤頁這種只有一個焦點的畫面。一般頁面不需要開。

<pipo-world middle="true">
  <!-- a single login card, floating in the middle -->
</pipo-world>

scroll Default 預設 "auto"Options 選項 auto / yes / no

Page scrolling 捲動控制

auto scrolls when content is taller than the window. yes always shows a scrollbar. no locks the page — use it only when you're sure everything fits, or the overflow gets clipped.

auto 是內容超出視窗才捲動,yes 是永遠顯示捲軸,no 是鎖住頁面——只有確定內容塞得下時才用,不然超出的部分會被裁掉。

<pipo-world scroll="no" middle="true">
  <!-- a full-screen page that never scrolls -->
</pipo-world>

Background Color · 背景顏色

Colors have names here.

在這裡,顏色是有名字的。

color Default 預設 "pibg"Options 選項 任何 Pipo 顏色名字 any Pipo color name

Background color 背景顏色

Fill in a Pipo color token — like mibble, wibble, or blonko. No hex codes, ever. Even when you use an image or a video, set a color too: it's the safety net underneath everything.

填一個 Pipo 色系 token——像 mibble、wibble、blonko。永遠不需要色碼。就算用了背景圖或影片,也建議填一個顏色,它是墊在最底下的安全網。

<pipo-world color="mibble">
  ...
</pipo-world>
color — tap a token to repaint the world! 點一個顏色,世界就換色! 
<pipo-world color="mibblewibbleblonkoplobbowhibbledunko">

If you type a token that doesn't exist, nothing breaks — the world quietly falls back to the default pibg.

就算填了一個不存在的顏色,畫面也不會壞掉——世界會安靜地退回預設的 pibg。

Background Image · 背景圖片

Hang a picture behind your world.

在你的世界後面掛一張圖。

image Default 預設 空白(沒有圖)Options 選項 圖片網址 image URL

Background image 背景圖片

Paste an image URL and it becomes the backdrop of your world. Leave it empty and there's simply no image. It sits on top of color, so if the image ever fails to load, your color shows instead.

貼一個圖片網址,它就變成世界的背景。留空就是沒有圖。圖片疊在 color 上面,所以圖片載入失敗時,顏色會接手。

<pipo-world
  image="https://example.com/bg.jpg"
  color="mibble"  <!-- safety net 安全網 -->
>
  ...
</pipo-world>

image-fit Default 預設 "cover"Options 選項 cover / contain / tile

How the image fills 圖片填滿方式

cover fills every pixel (edges may get cropped). contain shows the whole image (edges may show the color underneath). tile repeats the image like wallpaper.

cover 填滿每一格(邊緣可能被裁掉),contain 完整顯示整張圖(旁邊會露出底色),tile 像壁紙一樣重複拼貼。

<pipo-world image="bg.jpg" image-fit="tile">

Image position 圖片位置

Which part of the image stays visible when it gets cropped. top keeps the sky, bottom keeps the ground — pick the part you love.

圖片被裁切時,要保留哪一邊。top 留住天空,bottom 留住地面——留住你最喜歡的那一塊。

<pipo-world image="bg.jpg" image-align="top">

Image brightness 圖片亮度

Dim the image so your text stays readable on top of it. 100 is full brightness, 0 is pitch black. Around 50–70 usually makes white text pop nicely.

把圖片調暗,讓上面的文字看得清楚。100 是全亮,0 是全黑。50–70 左右通常能讓白色文字很漂亮。

image-sticky Default 預設 false(關)Options 選項 true(開)/ false(關)

Parallax effect 視差效果

When true, the image stays still while the page scrolls past it — a gentle parallax feeling. On iOS Safari and some Android browsers this can be unstable, so PipoToy falls back to normal scrolling there.

開啟後,頁面捲動時圖片留在原地不動,有種輕輕的視差感。在 iOS Safari 和部分 Android 瀏覽器上不穩定,PipoToy 會自動退回一般捲動。

<pipo-world image="bg.jpg" image-sticky="true">

Background Video · 背景影片

A world that moves.

一個會動的世界。

video Default 預設 空白(沒有影片)Options 選項 影片網址 video URL

Background video 背景影片

Paste a video URL and it plays behind everything — automatically muted, looping forever, no controls. It sits on the very top of the background stack. Always set a color too, for the moment before the video loads.

貼一個影片網址,它就在所有東西後面播放——自動靜音、無限循環、沒有控制列。它在背景疊層的最上面。記得也填一個 color,影片載入前的那一瞬間靠它撐場。

<pipo-world
  video="https://example.com/bg.mp4"
  color="dunko"
>
  ...
</pipo-world>

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🥞
Backgrounds stack like pancakes
From bottom to top: color → image → video. Color is always the fallback, so set one even when you use an image or video.
由底到頂:color → image → video。color 永遠是 fallback,就算用了圖片或影片也建議設定。
🛡️
Wrong values never break the world
A color token that doesn't exist, a typo in size — everything quietly falls back to its default. The page always looks fine.
不存在的顏色 token、size 打錯字——一切都會安靜退回預設值,畫面永遠是好看的。
📱
image-sticky is moody on phones
image-sticky="true" is unstable on iOS Safari and some Android browsers. PipoToy falls back to normal scrolling there, so your page still works — it just loses the parallax.
image-sticky="true" 在 iOS Safari 和部分 Android 上不穩定,PipoToy 會自動退回一般捲動,頁面照常運作,只是少了視差感。
✂️
scroll="no" clips overflowing content
Only lock scrolling when you're sure everything fits in the window. Anything taller gets cut off and can't be reached.
確定內容塞得進視窗再鎖捲動,超出的部分會被裁掉,而且滑不到。
🔤
pipo-world sets the family font
As the outermost shell, it defines font-family: "Nunito", "Noto Sans TC", sans-serif so every Pipo component inside inherits the same friendly voice.
身為最外殼,它定義了整個字型家族,裡面所有 Pipo 元件都繼承同一種友善的聲音。
🎨
"pibg" is the world's own color
The default color="pibg" maps to --pipotoy-blobia-pibg (#faf6ee) — the warm paper tone you're looking at right now. The framework handles the mapping internally.
預設的 pibg 對應 --pipotoy-blobia-pibg(#faf6ee),就是你現在看到的這個溫暖紙感底色。對應由框架內部處理。
