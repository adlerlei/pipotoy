Semantic color 語意色

Pick a mood. success (mint) is "all good", warn (butter) is "careful", error (rose) is "oh no". Skip it and you get the friendly mint default. An unknown value silently falls back to success — no broken boxes, no errors.

挑一個語意。success(薄荷綠)是「一切搞定」,warn(奶油黃)是「注意一下」,error(玫紅)是「糟糕」。不填就用預設的薄荷綠。寫錯的字也會安靜退回 success——不破圖、不報錯。

Sub-line 副標題

A smaller, quieter line under the title. Perfect for "what happened" or "what to do next". Skip it and the alert is a single bold sentence — great for short, punchy notifications.

Show or hide icon icon 開關

The left icon is built in — a small clay badge (check / bang / cross) that matches the type. Set icon="off" to hide it when you want pure text, like a quiet inline message.

左側的 icon 是內建的——一顆小小的黏土徽章(勾 / 驚嘆 / 叉),會跟著 type 變。設 icon="off" 就能關掉,適合想要純文字、安靜一點的場景。

Close button × 關閉按鈕

Add the bare dismiss attribute and a soft × button appears on the right. Click it and the whole alert quietly disappears. (Need to bring it back? Call element.show() in JS.)

寫一個 dismiss 屬性(不用填值),右邊就會浮出柔和的 × 按鈕。點下去整條 alert 安靜消失。(想叫回來？在 JS 裡呼叫 element.show() 就行。)

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🪄
Icons are baked in, not slotted
The three little badges (check / bang / cross) live inside the component's shadow DOM — you never write them. The same set shows up wherever you use type="success", warn, or error.
三顆小徽章(勾 / 驚嘆 / 叉)住在元件的 shadow DOM 裡——你不用寫。只要用 type="success"、warn、error,就會自己出現。
🎨
Semantic types, not raw color names
Type uses success / warn / error — not mibble / blonko / plobbo. That way the colors stay meaning-driven and the alert still makes sense if we ever swap them out for a different palette.
type 用的是 success / warn / error——不是 mibble / blonko / plobbo。這樣顏色保持語意導向,哪天我們換色票,alert 還是看得懂。
🛡️
Invalid values are silent
An unknown type falls back to success. icon with anything other than "off" keeps the icon on. Nothing logs, nothing breaks — the alert always shows up looking sensible.
不認得的 type 會退回 success。icon 只要不是 "off" 就會顯示 icon。不報錯、不破圖——alert 永遠看起來正常。
🧩
Dismissing is a one-way trip — until you call show()
Clicking × sets data-dismissed on the host. The element is just hidden via CSS, not removed from the DOM. If you need to bring it back, grab a reference in JS and call el.show().
點 × 會在 host 上設 data-dismissed,元件只是用 CSS 藏起來,並沒有從 DOM 移除。需要叫回來,在 JS 抓住它、呼叫 el.show() 就行。
