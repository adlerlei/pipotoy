<pipo-alert>

Say what happened, right where it matters.

Use an alert for a saved change, a warning, or an error. The default is ready for a simple success message.

在需要的位置說清楚發生了什麼

適合顯示儲存成功、注意事項或錯誤；只寫標籤內容，就是一則完成狀態通知。

 
<pipo-alert>Changes saved.</pipo-alert>
Live preview · 實際效果Changes saved.
Start Here

Three alerts you'll use most.

Start with the outcome. Add a second line only when the user needs context or a next step.

先說結果；只有需要補充原因或下一步時，再加入 desc。
01

Confirm a success

The default type is success, so keep it short.

確認完成：預設就是 success，簡短即可。
<pipo-alert>Profile updated.</pipo-alert>
Profile updated.
02

Explain a warning

Use a description for the action that comes next.

提醒注意：用 desc 告訴使用者下一步。
<pipo-alert type="warn"
  desc="Add a payment method to continue.">Action needed</pipo-alert>
Action needed
03

Let it be dismissed

Add dismiss for temporary messages the user can close.

暫時訊息：加上 dismiss，讓使用者自行關閉。
<pipo-alert type="error" dismiss>Upload failed.</pipo-alert>
Upload failed.

Reference

All four attributes.

Everything is optional. Open this only when you need exact values.

四個屬性都可省略；需要查精確選項時再展開。
Show all 4 attributes查看全部屬性
type

Message meaning
success / warn / error; default success

訊息語意；預設 success，無效值也會回到 success。
desc

Supporting line
Any plain text; default none

標題下方的補充文字；預設不顯示。
icon

Left status icon
Use off to hide; default on

左側狀態圖示；設為 off 即隱藏。
dismiss

Close button
Boolean; add it to enable

顯示關閉按鈕；加入屬性即可啟用。
Complete Example

A form status area.

Place the newest result near the form so the next action is obvious.

把最新結果放在表單附近，使用者就能立即理解狀態與下一步。
<pipo-alert type="success"
  desc="Your changes are now live.">Settings saved</pipo-alert>

<pipo-alert type="warn"
  desc="Verify your email to finish setup." dismiss>One step left</pipo-alert>
