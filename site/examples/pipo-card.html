Reference

All seven attributes.

Every attribute is optional; the slot holds the card body.

七個屬性都可省略；標籤中間的內容就是卡片內文。
Show all 7 attributes查看全部屬性
thumb

Color thumbnail
Any Pipo color; default none

頂部色塊縮圖；預設不顯示。
thumb-image

Image thumbnail
Any image URL; covers thumb

圖片縮圖；載入失敗時露出 thumb 色塊。
title

Card heading
Any text; default none

卡片標題；預設不顯示。
tag

Corner chip
Any short text; default none

右上角小標籤；適合短文字。
color

Tag color
Any Pipo color; default blonko

tag 的背景色；預設 blonko。
href

Whole-card link
Any URL; default none

讓整張卡片成為連結。
target

Open a new tab
Use blank with href

搭配 href 使用 blank，可另開分頁。
