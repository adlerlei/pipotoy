<pipo-card>

圖配字的資訊卡片

A clay-soft card that holds a picture, a title, and a few words.
Stack them in a grid for blogs, products, anything. No CSS.

一張黏土感的卡片,裝一張圖、一個標題、幾句話。
排成格子就是部落格、商品牆、什麼都行。不用寫 CSS。 

<pipo-card thumb="mibble" tag="教學" title="快速上手">三分鐘讓第一個 Pipo 元件動起來。</pipo-card>
三分鐘讓第一個 Pipo 元件動起來,只要一個標籤。

Look · 外觀

A thumbnail, a title, a tag.

一張縮圖、一個標題、一個小標籤。

thumb Default 預設 無(不顯示縮圖)Options 選項 任何 Pipo 顏色名字 any Pipo color name

Color-block thumbnail 色塊縮圖

Fill in a Pipo color token — like mibble or wibble — and the card grows a soft color block on top. No image needed; it's the fastest way to give a card a face. Leave it out and the card starts straight at the text.

填一個 Pipo 色系 token——像 mibble、wibble——卡片頂部就長出一塊柔和的色塊。不用圖片,這是給卡片一張臉最快的方法。不填就直接從文字開始。

<pipo-card thumb="mibble" title="綠綠的卡">頂部是一塊 mibble 綠。</pipo-card>
thumb — hover the cards, they float! 滑過卡片,會浮起來!
頂部一塊柔和的綠。 頂部一塊柔和的藍。 頂部一塊柔和的橘。
thumb-image Default 預設 無Options 選項 任何圖片網址 any image URL

Image thumbnail 圖片縮圖

Give it an image URL and that picture fills the top, cropped to fit nicely (object-fit: cover). It sits on top of thumb, so if the image fails to load, the color block quietly shows through instead of a broken icon.

給它一張圖片網址,圖片就鋪滿頂部,自動裁切到剛好(object-fit: cover)。它疊在 thumb 之上,所以萬一圖片載入失敗,會安靜露出底下的色塊,而不是破圖。

<pipo-card
  thumb="wibble"
  thumb-image="https://picsum.photos/400/300"
  title="有圖的卡">載入失敗會退回 wibble 色塊。</pipo-card>
thumb-image — real photos on top · 真的照片鋪在頂部
圖片鋪滿頂部,自動裁切。 圖片正常載入 圖片壞掉 → 露出 plobbo 色塊。 圖片失敗 → 色塊 fallback
title Default 預設 無Options 選項 任何文字 any text

Card heading 卡片標題

A short, bold heading that sits above the body text. Leave it out and the card is just the thumbnail and your words — perfectly fine for a quote or a photo caption.

一行粗體的短標題,坐在內文上方。不填的話,卡片就只有縮圖加你的文字——拿來放一句引言或照片說明剛剛好。

<pipo-card thumb="blonko" title="今日重點">標題會以粗體呈現。</pipo-card>
title — with and without · 有標題 vs 沒標題
標題在上,內文在下。 有 title 「沒有標題,只有一句話。」 —— 某隻 Pipo 無 title
tag Default 預設 無Options 選項 任何文字 any text

Corner chip 角落小標籤

A little pill that floats at the top-right corner — perfect for a category, a price, or a "New!". Its color comes from the color attribute below. Skip it and the corner stays clean.

一顆小膠囊,浮在右上角——拿來標分類、價格,或一句「New!」最適合。它的顏色來自下面的 color 屬性。不填角落就保持乾淨。

<pipo-card thumb="squorbo" tag="New!" color="plobbo" title="新品">右上角有顆 plobbo 小膠囊。</pipo-card>
tag — a chip in the corner · 角落的小膠囊
右上角一顆膠囊。 標籤標出分類。 標籤也能放價格。
color Default 預設 "blonko"Options 選項 任何 Pipo 顏色名字 any Pipo color name

Tag accent color 標籤強調色

Sets the background color of the tag chip. The text on it stays the same friendly dark tone on every color. Type a name that doesn't exist and it quietly falls back to blonko. (Only matters when you have a tag.)

設定 tag 小膠囊的底色。膠囊上的文字在每個顏色上都維持同一種友善的深色。填了不存在的名字也不會壞,會安靜退回 blonko。(只有在有 tag 時才有作用。)

<pipo-card tag="熱門" color="glorix" title="色票">膠囊底色換成 glorix。</pipo-card>
color — same chip, different colors · 同一顆膠囊,不同顏色
膠囊 = mibble。 膠囊 = glorix。 膠囊 = wibble。
Behavior · 行為

Plain card, or clickable.

純卡片,或整張可點。

href Default 預設 空白(純卡片)Options 選項 任何網址 any URL

Make it a link 整卡變連結

Leave href empty and the card is a plain <div> container. Give it a URL and the whole card becomes one big <a> — click anywhere on it to navigate, with keyboard focus built in. You write one tag; PipoToy picks the right element.

href 留空,卡片就是一個純 <div> 容器。填上網址,整張卡就變成一個大大的 <a>——點任何地方都會跳轉,鍵盤聚焦也內建好了。你只寫一個標籤,PipoToy 幫你選對的元素。

<!-- 純卡片 plain card -->
<pipo-card thumb="blonko" title="純展示">不會跳轉。</pipo-card>

<!-- 可點卡片 clickable card -->
<pipo-card thumb="wibble" title="看元件" href="./components.html">點整張卡跳頁。</pipo-card>
href — the right one really navigates! 右邊那張真的會跳頁!
點下去什麼都不會發生。 no href <div> 點整張卡 → 元件總覽。 href="…" <a>
target Default 預設 空白(原分頁)Options 選項 blank

Open in a new tab 開新分頁

By default a card link opens in the same tab. Add target="blank" and it opens in a new tab instead — PipoToy automatically adds rel="noopener noreferrer" for you, so it's safe. Only works together with href; plain cards ignore it.

預設卡片連結在原分頁開啟。加上 target="blank" 就會改在新分頁開——PipoToy 會自動幫你補上 rel="noopener noreferrer",安全無虞。只有搭配 href 才有用,純卡片會忽略它。

<pipo-card
  thumb="squorbo"
  title="開新分頁"
  href="https://github.com/adlerlei/pipotoy"
  target="blank">在新分頁打開 GitHub。</pipo-card>
target — the right one opens a new tab! 右邊那張會另開新分頁!
在原分頁跳轉。 no target same tab 原分頁 在新分頁打開 GitHub。 target="blank" new tab 新分頁

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🧱
It floats when you hover
Every card lifts up a little with a springy clay ease when you hover it — clickable or not. That playful bounce is built in; you never style it yourself.
每張卡滑過時都會帶著彈簧感輕輕浮起來——不管能不能點。那種俏皮的彈跳是內建的,你永遠不用自己刻。
🔀
One tag, div or link
No href → a plain <div> card. With href → the whole card is one <a> (Tab to focus, click anywhere to navigate). You never choose the element yourself.
沒有 href → 純 <div> 卡片。有 href → 整張卡是一個 <a>(Tab 聚焦、點任何地方都跳轉)。你永遠不用自己選元素。
🛡️
A broken image never breaks the card
If thumb-image fails to load, the card quietly shows the thumb color block underneath instead of a broken-image icon. Wrong color tokens fall back too — no errors, no blank cards.
如果 thumb-image 載入失敗,卡片會安靜露出底下的 thumb 色塊,而不是破圖示。錯誤的顏色 token 也會 fallback——不報錯、不空白。
🧩
Drop them in any grid
A card is display: block and fills whatever space you give it. Put a few in a CSS grid and you've got a responsive gallery — the card handles its own clay look, you handle the layout.
卡片是 display: block,會填滿你給它的空間。在 CSS grid 裡放幾張,就是一個 RWD 圖庫——卡片管自己的黏土外觀,你管排版。
