Look · 外觀

Pick a color, a size, a shape.

挑一個顏色、一個大小、一個形狀。

color Default 預設 "blonko"Options 選項 任何 Pipo 顏色名字 any Pipo color name

Background color 背景顏色

Fill in a Pipo color token — like mibble, wibble, or plobbo. No hex codes, ever. The text color stays the same friendly dark tone on every color. Type a name that doesn't exist and it quietly falls back to blonko.

填一個 Pipo 色系 token——像 mibble、wibble、plobbo。永遠不用色碼。文字顏色在每個底色上都維持同一種友善的深色。填了不存在的名字也不會壞,會安靜退回 blonko。

Full width 滿版寬度

Add full and the button stretches to fill its container — perfect for forms and mobile screens. A full-width button is always square, so even if you write shape="pill", it renders square.

加上 full,按鈕就會撐滿整個容器寬度——表單和手機畫面最適合。滿版按鈕一律是 square,所以就算你寫了 shape="pill",也會以方形呈現。

Motion · 動作

Two ways to come alive.

兩種活起來的方式。

anim Default 預設 "float"Options 選項 float / tilt

Hover animation 滑過動畫

float lifts the button straight up when you hover. tilt tips it playfully to one side. Both squish down with a springy bounce when pressed — and tilt stays tilted while you hold it.

float 是滑過時筆直浮起來。tilt 是俏皮地往一邊歪。兩種按下去都會帶著彈簧感壓扁——而且 tilt 按住時會保持傾斜,不會歸正。

Behavior · 行為

Button or link — it knows.

按鈕還是連結——它自己會判斷。

href Default 預設 空白(是按鈕)Options 選項 任何網址 any URL

Make it a link 變成連結

Leave href empty and you get a real <button>. Give it a URL and the very same tag becomes a real <a> link — same look, same feel, but it navigates. You write one tag; PipoToy picks the right element.

href 留空,你得到一顆真正的 <button>。填上網址,同一個標籤就變成真正的 <a> 連結——外觀手感一模一樣,但它會跳轉。你只寫一個標籤,PipoToy 幫你選對的元素。

<!-- 按鈕 button -->
<pipo-tap color="blonko">送出</pipo-tap>

<!-- 連結 link -->
<pipo-tap color="wibble" href="./components.html">了解更多</pipo-tap>
href — the right one really navigates! 右邊那顆真的會跳頁!
送出no href <button> 了解更多href="…" <a>
target Default 預設 空白(原分頁)Options 選項 blank

Open in a new tab 開新分頁

By default a link opens in the same tab. Add target="blank" and it opens in a new tab instead — PipoToy automatically adds rel="noopener noreferrer" for you, so it's safe. Only works together with href; plain buttons ignore it.

預設連結在原分頁開啟。加上 target="blank" 就會改在新分頁開——PipoToy 會自動幫你補上 rel="noopener noreferrer",安全無虞。只有搭配 href 才有用,純按鈕會忽略它。

<!-- 原分頁 same tab -->
<pipo-tap color="wibble" href="./components.html">同分頁</pipo-tap>

<!-- 新分頁 new tab -->
<pipo-tap color="squorbo" href="./components.html" target="blank">開新分頁</pipo-tap>
target — the right one opens a new tab! 右邊那顆會另開新分頁!

type Default 預設 "button"Options 選項 button / submit / reset

Button type 按鈕類型

For buttons inside a <form>: submit sends the form, reset clears it, button does nothing on its own. This only matters when there's no href — links don't submit forms.

給表單 <form> 裡的按鈕用:submit 送出表單,reset 清空,button 自己不做事。只有在沒有 href 時才有意義——連結不會送出表單。

<form>
  <pipo-tap color="mibble" type="submit">送出表單</pipo-tap>
  <pipo-tap color="flumpo" type="reset">清空</pipo-tap>
</form>

disabled Default 預設 false(關)Options 選項 加上就停用 add it to disable

Turn it off 停用

Add disabled and the button fades, stops responding to hover or press, and shows a "not-allowed" cursor. It also tells screen readers it's off via aria-disabled. If a disabled button has an href, the link is removed too — so it really can't be clicked.

加上 disabled,按鈕會變淡、不再回應滑過或按下,游標變成「禁止」符號。它也會透過 aria-disabled 告訴螢幕報讀軟體它被關掉了。如果停用的按鈕本來有 href,連結也會一併移除——所以它真的點不動。

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🫳
It squishes when you press
Hover lifts it up with a springy ease; press pushes it down fast (80ms) into the clay. That two-speed feel is what makes it feel real.
滑過時帶彈簧感浮起,按下時快速(80ms)壓進黏土裡。這種一快一慢的手感,就是它像真的的原因。
🔀
One tag, button or link
No href → a real <button> (keyboard + Enter works). With href → a real <a> (Tab to focus, click to navigate). You never choose the element yourself.
沒有 href → 真的 <button>(鍵盤 + Enter 可觸發)。有 href → 真的 <a>(Tab 聚焦、點擊跳轉)。你永遠不用自己選元素。
🛡️
Wrong color never breaks it
A color token that doesn't exist quietly falls back to blonko. No errors, no blank button — it always looks fine.
不存在的顏色 token 會安靜退回 blonko。不報錯、不空白——它永遠是好看的。
📐
full always means square
A full-width button renders square no matter what shape you write — a full-width pill looks odd, so PipoToy makes the call for you.
滿版按鈕一律以 square 呈現,不管你寫了什麼 shape——滿版的膠囊形不好看,所以 PipoToy 幫你決定。
