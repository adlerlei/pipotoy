<pipo-row>

Split a row into exact columns.

Use pipo-row when a layout needs precise proportions. Each pipo-col declares how many columns it spans.

把一列精確切成需要的比例

需要明確欄寬時使用 pipo-row；每個 pipo-col 以 span 決定佔幾欄。

<pipo-row>
  <pipo-col span="6">Left</pipo-col>
  <pipo-col span="6">Right</pipo-col>
</pipo-row>

Reference

Two row attributes, one col attribute.

The grid is precise by design and does not change spans at mobile breakpoints.

此元件不會在手機自動改變 span；需要自然換行時，優先考慮 cluster 或 stack。
Show all 3 attributes查看全部屬性
gap

Cell spacing
none / small / medium / large; default medium

pipo-row 的格子間距；預設 medium。
cols

Total columns
Integer 2–12; default 12

pipo-row 的總欄數；無效值回到 12。
span

Columns occupied
Integer 1–12; default 1

pipo-col 佔用欄數；無效值回到 1。
Complete Example

A dashboard summary row.

Give the main metric twice the space of each supporting metric.

主要數字佔 6 欄，兩個輔助數字各佔 3 欄。
<pipo-row gap="small">
  <pipo-col span="6">Total sales</pipo-col>
  <pipo-col span="3">Orders</pipo-col>
  <pipo-col span="3">Returns</pipo-col>
</pipo-row>
