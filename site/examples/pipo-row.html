<pipo-row>

12 欄精確排版 — 給複雜版面用的 Grid 系統

Lay things out on a precise 12-column grid. Pair with <pipo-col> to control
each cell's width — no flex math, no calc(), just span.

把元素精確放在 12 欄的格子上。搭配 <pipo-col> 決定每格佔幾欄 —
不需要算 flex、不需要寫 calc()，只要寫 span。 

<pipo-row gap="medium">
  <pipo-col span="6">左半</pipo-col>
  <pipo-col span="6">右半</pipo-col>
</pipo-row>

pipo-row · Total columns

Change the grid size.

cols Default 預設 12Range 範圍 2 - 12

Total columns 總欄數

12 is the default (industry standard — Bootstrap, Material, Tailwind all use 12). Use cols="3" for easy thirds, cols="4" for quarters, cols="2" for halves. Invalid values fall back silently to 12.

12 是預設值（業界標準 — Bootstrap、Material、Tailwind 都用 12）。cols="3" 直接做三等分、cols="4" 做四等分、cols="2" 做兩半。無效值安靜退回 12。

pipo-col · Span

How wide is each cell?

決定每格佔幾欄。

span Default 預設 1Range 範圍 1 - 12

Column span 佔幾欄

span="6" on a 12-col row = half width. span="4" = one third. span="3" = one quarter. Mix spans freely: span="8" + span="4" for an 8/4 split, span="6" + span="3" + span="3" for 50/25/25. Invalid values fall back silently to 1.

span="6" 在 12 欄裡就是半寬。span="4" 是 1/3、span="3" 是 1/4。可以混搭：span="8" + span="4" 做出 8/4 不等比、span="6" + span="3" + span="3" 做出 50/25/25。無效值安靜退回 1。

<pipo-row gap="medium">
  <pipo-col span="8">主要內容（寬）</pipo-col>
  <pipo-col span="4">側欄（窄）</pipo-col>
</pipo-row>

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🎯
When to reach for pipo-row
Cluster and stack are for simple, flexible layouts (auto-wrap, auto-gap). pipo-row is for precise layouts where proportions matter — sidebars, dashboards, magazine grids. If you don't need precise widths, cluster is friendlier.
cluster 跟 stack 給簡單、彈性的版面（自動換行、自動等距）。pipo-row 給精確的版面，比例真的要對的那種 — 側欄、儀表板、雜誌型網格。如果不需要精確寬度，cluster 更友善。
🔢
span can exceed cols
If a span on one col is larger than the row's cols, the grid still works — the cell just extends past the row width. There's no error, just an overflow. This is useful if you want one item to "break out."
如果某個 span 比 row 的 cols 大，grid 還是會跑 — 該格會超出 row 的寬度。不報錯，只是溢出。偶爾你想讓某個元素「突破框架」時很實用。
📦
Non-pipo-col children work too
Plain <div>s, <section>s, even raw text — anything you put in pipo-row becomes a grid item with default span="1". So you can mix <pipo-col> with vanilla elements freely.
普通的 <div>、<section>、甚至純文字 — 任何丟進 pipo-row 的東西都會變成 grid item，預設 span="1"。所以 <pipo-col> 跟原生元素可以混著用。
📱
No responsive breakpoints in v1
pipo-row doesn't have md-span or breakpoint overrides yet — that's by design. For responsive precision, use cluster for "this should wrap" and stack for "this should always be vertical on mobile." Use row when you're confident the layout fits the screen.
pipo-row v1 沒有響應式斷點覆寫（md-span 之類）— 這是刻意的。要響應式精確排版，cluster 負責「塞不下要換行」、stack 負責「手機一定要垂直」。確定版面不會爆時才用 row。
🛡️
Invalid values are silent
Unknown gap falls back to medium. Out-of-range cols (e.g., "15" or "abc") falls back to 12. Out-of-range span (e.g., "0" or "99") falls back to 1. No errors, no broken grids.
不認得的 gap 退回 medium。超出範圍的 cols（如 "15" 或 "abc"）退回 12。超出範圍的 span（如 "0" 或 "99"）退回 1。不報錯、不破版。
