<pipo-note>

Give the extra words their own quiet place.

Use it for translations, supporting context, tips, or an aside that should feel separate without becoming an alert.

適合放翻譯、補充背景、提示或題外話。它會與主要內容清楚分開，但不會搶走注意力。 
<pipo-note>
  中文補充集中放在這裡。
</pipo-note>
Live preview 中文補充集中放在這裡，不與英文逐句交錯。
Line

Choose how strongly it separates.

Medium is the everyday default. Thin stays subtle; thick gives the note more presence.

線條有細、中、粗三種。一般補充使用 medium；想低調一點選 thin，想更明顯則用 thick。

Thin

line="thin"
A small aside that stays in the background.

Medium

line="medium"
A clear separator for everyday supporting text.

Thick

line="thick"
A stronger note that should be noticed first.
Color

Match the line to the page.

Any Pipo color name works. Only the line changes; your text keeps the surrounding text color.

color 只改左側線條，文字仍沿用頁面的字色，因此不會犧牲閱讀性。

Wibble

color="wibble"
Cool and calm for translations.

Mibble

color="mibble"
Soft and friendly for helpful tips.

Plobbo

color="plobbo"
Warm and playful for a personal aside.
Quick Reference

Two choices. That's all.

Leave both out for the recommended wibble medium line.

兩個屬性都可以不寫，預設就是 wibble 色的中等線條。
color Line color

Any Pipo color name. Default: wibble. Invalid names fall back safely.

line Line thickness

thin / medium / thick. Default: medium. Invalid values use medium.

Complete Example

English first. Chinese as one calm block.

Keep each language in its own reading flow instead of alternating sentence by sentence.

英文先完整說完，再把中文集中成一段，閱讀節奏會更清楚。 
<h2>Choose a shape</h2>
<p>Pill is a capsule. Rounded is a soft rectangle.</p>

<pipo-note color="wibble" line="medium">
  pill 是膠囊；rounded 是柔和圓角矩形。
</pipo-note>
