<pipo-cluster>

水平群聚 — 一左一右，自動換行

Line things up horizontally, and wrap when they run out of room.
Buttons, chips, badges — whatever wants to sit side by side.

把東西由左往右水平排成一線，太擠自動換行、每個之間等距。
按鈕列、標籤列、徽章 — 想排排站的元素都適用。 

<pipo-cluster gap="small"align="center">
  <button>主要</button>
  <button>次要</button>
  <button>取消</button>
</pipo-cluster>

Drop anything inside — buttons, chips, badges, icons, even text. Items sit side by side; when they don't fit, they wrap to a new line. No flex, no media queries, no math.

中間可以放任何東西 — 按鈕、標籤、徽章、icon、純文字。元素排成一線；塞不下自動換到下一行。不需要 flex、不需要 media query、不需要算數。

Spacing · 間距

Four gap sizes.

四種間距尺寸。

gap Default 預設 "medium"Options 選項 "none" / "small" / "medium" / "large"

Horizontal spacing 水平間距

Four friendly sizes: none (touching), small (8px) for chip lists, medium (12px) for buttons, large (20px) for breathing room between bigger elements.

四種好懂的尺寸：none 黏在一起、small（8px）標籤列用、medium（12px）按鈕列用、large（20px）大元素之間留呼吸空間用。

<pipo-cluster gap="small">
  <span class="chip">標籤 A</span>
  <span class="chip">標籤 B</span>
  <span class="chip">標籤 C</span>
</pipo-cluster>

Alignment · 對齊

Vertical alignment for mixed heights.

當元素高矮不同，垂直對齊就很重要。

align Default 預設 "center"Options 選項 "start" / "center" / "end" / "stretch"

Vertical alignment 垂直對齊

When items are different heights, this is your friend. start pins everything to the top, center (default) centers them, end pins to the bottom, stretch makes them all the same height (useful for equal-size cards in a row).

元素高矮不同時，這個屬性就很重要。start 全部靠上、center（預設）垂直置中、end 全部靠下、stretch 把所有元素拉到同高（等高卡片列很實用）。

<pipo-cluster align="stretch" gap="medium">
  <div class="card card-tall">高的</div>
  <div class="card card-short">矮的</div>
</pipo-cluster>

Wrapping · 自動換行

When they don't fit, they wrap.

塞不下就自動換下一行。

pipo-cluster always wraps when there's no room — no extra attribute needed. Resize the browser window on the demos above (especially the chip list and the action buttons) to watch items reflow naturally. This is the killer feature for responsive design without media queries.

pipo-cluster 在空間不夠時永遠會自動換行 — 不用額外屬性。縮放瀏覽器視窗（特別是標籤列跟按鈕列的範例），看元素自然地重新排列。這是響應式設計不用 media query 的殺手鐧。

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🌊
Wrapping is always on
There's no wrap="off" switch — pipo-cluster always wraps when items run out of horizontal room. This is the whole point of the component. If you really need a non-wrapping row (rare), use a plain <div> with display:flex.
沒有 wrap="off" 開關 — pipo-cluster 在元素超出水平空間時永遠會換行，這就是這個元件的全部意義。如果你真的需要一個不換行的列（罕見），用普通的 <div> 加 display:flex。
📏
align="stretch" respects intrinsic min-content
stretch makes items the same height as the tallest sibling — but never smaller than their natural content. A single-line label won't suddenly become a 100px tall block; it'll stay exactly as tall as its text needs.
stretch 讓所有元素拉到跟最高的兄弟一樣高 — 但不會比自己的自然內容小。一行文字標籤不會突然變成 100px 高的方塊，它就只會保持文字需要的高度。
🎯
Two attributes, one job
pipo-cluster does exactly one thing: lay out children horizontally with equal gap and configurable vertical alignment. No justification, no reverse, no masonry — those belong elsewhere. Tiny API, easy to learn.
pipo-cluster 只做一件事：用等距加可設定的垂直對齊，把子元素水平排起來。沒有 justify、沒有反轉、沒有瀑布流 — 那些歸其他地方管。API 越小越好學。
🛡️
Invalid values are silent
An unknown gap falls back to medium. An unknown align falls back to center. No errors, no broken layouts — the cluster always shows up looking sensible.
不認得的 gap 退回 medium。align 退回 center。不報錯、不破版 — cluster 永遠看起來正常。
