Learn One Control at a Time

Change one thing, then see what moves.

Each example changes one layout control: width, inner spacing, or horizontal position.

以下每個範例只解釋一件事：內容寬度、內側留白，或內容的水平位置。

1. Set the content width

size="narrow" limits the inner content to a readable column. It does not add padding.

size 只限制內容最大寬度，不會增加四周留白。
<pipo-page size="narrow">
  A readable text column
</pipo-page>
This inner column stops at the narrow width.

2. Add space inside the page

space="large" adds padding between the page edge and its content.

space 控制內容與頁面邊緣之間的內側留白。
<pipo-page space="large">
  Content with generous breathing room
</pipo-page>
The empty area around this box comes from space.

3. Move a narrow column

align="right" moves a width-limited content column to the right edge.

align 會移動已限制寬度的內容欄；內容滿版時不容易看出差異。
<pipo-page size="narrow"
  align="right">
  A narrow column on the right
</pipo-page>
This narrow column sits on the right.
Reference

All fourteen attributes.

Start with layout and color. Image, video, and scroll controls are for specific full-page experiences.

先掌握版面與顏色；圖片、影片與捲動控制只在特定整頁情境使用。
Show all 14 attributes查看全部屬性
size

Content width
full / wide / medium / narrow; default full

內容最大寬度。
fill

Minimum height
screen / none; default screen

是否至少填滿一個螢幕高度。
space

Content padding
0 / small / medium / large; default 0

內容四周留白，手機會自動縮小。
align

Horizontal position
left / center / right; default center

內容容器的水平位置。
middle

Vertical centering
Boolean; default off

加入屬性即可垂直置中內容。
scroll

Page scrolling
auto / no; default auto

設為 no 會鎖住整頁捲動，請只用於全螢幕體驗。
color

Background color
Any Pipo color; default pibg

最底層背景顏色。
image

Background image
Any image URL; default none

背景圖片網址。
image-fit

Image sizing
cover / contain / tile; default cover

圖片填滿方式。
image-align

Image position
CSS position value; default center

例如 center、top、left center。
image-light

Image brightness
0–100; default 100

數字越低，背景圖片越暗。
image-sticky

Fixed background
Boolean; default off

桌面使用固定背景；手機自動降級為一般捲動。
video

Background video
Video URL; default none

背景影片會靜音、循環並填滿畫面。
video-light

Video brightness
0–100; default 100

數字越低，背景影片越暗。
