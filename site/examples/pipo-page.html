Step 1 · Page size

How much room does your content need?

Height, width, and breathing room are three different choices. Change them one at a time.

畫面要多大？

高度、寬度和四周留白是三件不同的事。一次看一個，就不會混在一起。
1

How tall should the page be?

A full screen works for a homepage. Content height works for a smaller section.

畫面要多高？

整個螢幕適合首頁；跟著內容適合一般段落。

fill
If you write nothing: it fills one screen.什麼都不寫時：會填滿一個螢幕。

Fill the screen

Great for the first view of a homepage.

填滿螢幕適合首頁第一幕。
Content
<pipo-page fill="screen">...</pipo-page>

Follow the content

Great for a normal section.

跟著內容適合一般段落。
Content
<pipo-page fill="none">...</pipo-page>
2

How wide should the content be?

The background stays full width. Only the content width changes.

內容要多寬？

背景永遠是滿版；這裡只改變文字與元件可以站多寬。

size
If you write nothing: the content uses the full width. On phones, every choice fits the screen automatically.什麼都不寫時：內容使用全部寬度；手機上會自動縮成適合螢幕的寬度。

Step 2 · Content position

Where should the content stand?

Use horizontal for left and right. Use vertical for top and bottom.

內容要站在哪裡？

左右看 horizontal，上下看 vertical。名稱和方向完全一樣，不用猜。
4

Left, center, or right?

The difference is easiest to see with narrow content.

靠左、置中，還是靠右？

搭配窄版內容時，位置最容易看出來。

horizontal
If you write nothing: the content is centered horizontally.什麼都不寫時：內容會水平置中。

Step 3 · Background

Color, image, or video?

Start with a color. Add an image or video when the page needs a stronger mood.

背後要放什麼？

先從顏色開始。需要更強烈的情境時，再加入圖片或影片。
6

Choose a background color

Use the name of a character from the Pipo color family.

換一個背景顏色

直接填入 Pipo 色彩角色的名字。

color
If you write nothing: the page uses the creamy pibg color.什麼都不寫時：使用奶油色 pibg。

8

How should the image fit?

Fill the area, show the whole image, or repeat it like wallpaper.

圖片要怎麼放進畫面？

填滿、完整顯示，或像壁紙一樣重複。

image-fit
If you write nothing: the image fills the whole area.什麼都不寫時：圖片會填滿整個畫面。

Cover

Fills the area and may crop a little.

填滿畫面可能裁掉一小部分。
image-fit="cover"

Contain

Shows everything and may leave space.

完整顯示可能留下空白。
image-fit="contain"

Tile

Repeats like wallpaper.

重複鋪滿像壁紙一樣排列。
image-fit="tile"

Which part of the image matters most?

When the image is cropped, keep the top, center, or bottom in view.

圖片最重要的地方要留在哪裡？

圖片被裁切時，可以決定保留上方、中間或下方。

image-align

數字越小，圖片越暗，淺色文字就越清楚。

One last thing

Most pages never need to change this.

Only games, exhibition screens, or fixed control panels may need to stop the page from scrolling.

一般頁面不用改這個

只有遊戲、展場畫面或固定操作面板，才可能需要禁止捲動。
14

Should the whole page scroll?

Use auto for normal content. no locks the whole page in place.

要不要讓整個頁面捲動？

一般內容請維持 auto；no 會把整個頁面鎖住。

scroll
If you write nothing: the page scrolls normally.什麼都不寫時：可以正常捲動。
