Spacing · 間距

Four sizes, one attribute.

四種尺寸，一個屬性切換。

gap Default 預設 "medium"Options 選項 "none" / "small" / "medium" / "large"

Vertical spacing 垂直間距

Four friendly sizes: none (no gap), small (8px) for tight lists, medium (16px) for paragraphs and cards, large (24px) for breathing room between sections. Skip it and you get medium — a safe everyday default.

四種好懂的尺寸：none 黏在一起、small（8px）緊湊列表用、medium（16px）段落卡片用、large（24px）區塊之間留呼吸空間用。不填就用 medium — 通用預設、不出錯。

<pipo-stack gap="small">
  <p>緊湊排列...</p>
  <p>間距很小</p>
</pipo-stack>

<pipo-stack gap="large">
  <h3>標題</h3>
  <p>說明...</p>
</pipo-stack>

Nesting · 巢狀用法

Stack inside Stack. Stack around Cluster.

Stack 裡面可以再放 Stack，外面可以包 Cluster。

The real power of pipo-stack is composition. A page section is usually: title → description → a row of buttons. That's a stack containing a heading, a paragraph, and a cluster of buttons — vertical, then horizontal inside one slot.

pipo-stack 的真正威力在於組合。一個頁面區塊通常是：標題 → 說明 → 一排按鈕。這就是 stack 包標題、段落、再包一個 cluster — 垂直中藏一段水平。

<pipo-stack gap="medium">
  <h3>開始你的旅程</h3>
  <p>三個按鈕水平排列在一行（Cluster 自動排）</p>
  <pipo-cluster gap="small">
    <pipo-button color="blonko">開始</pipo-button>
    <pipo-button>看文件</pipo-button>
    <pipo-button>更多</pipo-button>
  </pipo-cluster>
  <p>結尾說明...</p>
</pipo-stack>

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

🎯
One attribute, one job
pipo-stack does exactly one thing: stack children vertically with equal spacing. No alignment, no justification, no columns — those belong to pipo-cluster or (later) pipo-grid. Keeping the API tiny means there's nothing to learn.
pipo-stack 只做一件事：垂直堆子元素並保持等距。沒有對齊、沒有水平分佈、沒有欄位 — 那些歸 pipo-cluster 或之後的 pipo-grid 管。API 越小，學得越快。
🧩
Direct children only
The gap only applies to direct children of pipo-stack. If you put a <div> around three paragraphs and put that inside the stack, only the wrapping div gets the gap — its inner paragraphs will sit flush together. Wrap each block in its own pipo-stack if you need finer control.
間距只作用於 pipo-stack 的直接子元素。如果你用 <div> 包了三段再放進 stack，只有那個外層 div 會吃到間距，裡面的段落會黏在一起。需要更細的控制，就各自包一個 pipo-stack。
📱
Responsiveness is the parent's job
pipo-stack doesn't know about screen widths — it just stacks. When you need different layouts on mobile vs desktop, wrap it in pipo-page or (soon) pipo-grid, and let them handle the breakpoints.
pipo-stack 不知道螢幕寬度 — 它只管垂直堆。需要手機/電腦不同排版，把它包進 pipo-page 或之後的 pipo-grid，讓它們處理斷點。
🛡️
Invalid values are silent
An unknown gap value silently falls back to medium. No errors, no broken layouts — the stack always shows up looking sensible.
不認得的 gap 值會安靜退回 medium。不報錯、不破版 — stack 永遠看起來正常。
