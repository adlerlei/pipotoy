<pipo-navbar>

Give every page a clear way home.

Start with a brand name and a few links. The navbar turns into a mobile menu automatically.

讓每一頁都有清楚的回家路線

先放品牌名稱與幾個連結；手機寬度時會自動變成漢堡選單。

<pipo-navbar
  logo="PipoToy"
  links="Home:/,Components:/components">
</pipo-navbar>

Start Here

Three navbars you'll use most.

Begin with navigation, then add one primary action or a small set of social links.

先完成基本導覽，再視需求加入一個主要行動或少量社群連結。
01

Basic navigation

Brand, icon, and three links.

基本導覽：品牌、圖示與三個連結。
logo="PipoToy" logo-icon="🧸"
links="Home:/,Docs:/docs,About:/about"
02

Add one CTA

Keep the most important next step visible.

主要行動：讓最重要的下一步一直可見。
cta="Get started" cta-href="/start"
03

Add social links

Supported platform names become icons.

社群連結：支援的平台名稱會自動變成圖示。
socials="github:#,instagram:#"

Reference

All thirteen attributes.

The common recipe needs only logo and links; the rest refine brand, action, and social behavior.

一般情況只需 logo 與 links；其餘屬性用來調整品牌、行動按鈕與社群連結。
Show all 13 attributes查看全部屬性
logo

Brand text
Any text; default empty

品牌名稱文字。
logo-icon

Brand icon
Emoji or short text; default empty

品牌旁的 emoji 或短圖示。
logo-image

Brand image
Image URL; overrides logo-icon

品牌圖片網址；優先於 logo-icon。
color

Accent color
Any Pipo color; default mibble

品牌與選取狀態的強調色。
bar-color

Bar background
Any Pipo color; default glass

整條導覽列背景色；預設霧面白。
links

Navigation links
Label:URL,…

以逗號分隔多組「名稱:網址」。
cta

Button text
Any text; empty hides button

行動按鈕文字；空白時不顯示。
cta-color

Button color
Any Pipo color; defaults to color

按鈕顏色；預設沿用 color。
cta-shape

Button shape
pill / rounded; default pill

按鈕形狀；膠囊或圓角矩形。
cta-anim

Hover motion
float / tilt; default float

按鈕滑過動畫。
cta-href

Button URL
Any URL; default empty

加入網址後，按鈕會成為連結。
cta-target

Link target
_self / _blank; default _self

控制是否另開分頁。
socials

Social links
platform:URL,…

支援 Facebook、Instagram、X、GitHub、YouTube、TikTok、LinkedIn。
Complete Example

A complete product navbar.

Brand, primary pages, social proof, and one clear action.

品牌、主要頁面、社群入口與一個清楚行動都放在同一條導覽列。
<pipo-navbar
  logo="PipoToy" logo-icon="🧸"
  links="Home:/,Components:/components,Colors:/colors"
  color="mibble" cta="Get started"
  cta-color="blonko" cta-href="/start"
  socials="github:#,instagram:#">
</pipo-navbar>
