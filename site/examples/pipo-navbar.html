<pipo-navbar>

膠囊懸浮導覽列

A frosted-glass nav bar that floats at the top of every page.
Logo, links, a CTA button, social icons — one tag, no CSS.

磨砂玻璃質感的導覽列，懸浮在頁面頂部。
Logo、連結、CTA 按鈕、社群圖示——一個標籤，不用寫 CSS。 

<pipo-navbar
  logo="我的品牌"
  logo-icon="🌟"
  color="mibble"
  links="首頁:/,作品集:/portfolio,關於:/about"
  cta="聯繫我"
  cta-href="/contact"
></pipo-navbar>

Logo · 識別

Your brand, three ways.

三種方式放你的識別。

logo Default 預設 ""Options 選項 任何字串 any string

Brand name text 品牌名稱文字

The text shown as the brand name. If you also set logo-icon, a colored icon block appears before the text. If neither icon nor image is set, the first letter of logo is used as the icon.

品牌名稱文字。如果同時設了 logo-icon，會在文字左側出現一個彩色小方塊。如果 icon 和 image 都沒設，logo 的第一個字會自動變成圖示。

<pipo-navbar logo="PipoToy"></pipo-navbar>
logo — the first letter auto-becomes the icon! 第一個字母自動變圖示!
logo="PipoToy"
logo="" (空白)
logo-icon Default 預設 ""Options 選項 任何 emoji any emoji

Emoji icon beside the logo logo 旁的 emoji 圖示

Put an emoji in the colored icon block next to the brand name. Hidden automatically when logo-image is set.

在品牌名稱旁的彩色小方塊放 emoji。設了 logo-image 時自動隱藏。

<pipo-navbar logo="我的網站" logo-icon="🌟"></pipo-navbar>
logo-icon
logo-icon="🌟"
logo-icon="🧸"
logo-image Default 預設 ""Options 選項 圖片 URL image URL

Image logo 圖片 logo

Point to a PNG, SVG, or any image file. It's capped at 32px tall and 120px wide, so it never stretches the bar. When set, logo-icon is hidden. If the image fails to load, it falls back to logo-icon — or, if that's also empty, the first letter of logo in a colored circle.

填圖片 URL（PNG、SVG 都可以）。高度固定 32px、最寬 120px，不會把 bar 撐高。設了之後 logo-icon 自動隱藏。圖片載入失敗時，退回顯示 logo-icon；如果 icon 也沒設，就顯示 logo 首字母。

<pipo-navbar
  logo="PipoToy"
  logo-icon="🧸"
  logo-image="./logo.png"
></pipo-navbar>

Nav · 導覽

Color and links.

強調色與導覽連結。

color Default 預設 "mibble"Options 選項 任何 Pipo 色名 any Pipo token

Accent color token 強調色 token

Sets the accent color for three things at once: the logo icon background, the active nav link highlight, and the default CTA button color. Use any Pipo color token name — mibble, wibble, blonko… An invalid token quietly falls back to mibble.

一次設定三個地方的強調色：logo 圖示背景、當前連結的高亮、CTA 預設顏色。用任何 Pipo 色系 token 名字都行。填了不存在的名字也不會壞，會安靜退回 mibble。

<pipo-navbar logo="Brand" logo-icon="✦" color="plobbo"></pipo-navbar>
color — one token, three places at once · 一個 token 同時影響三個地方
bar-color Default 預設 ""（霧面白玻璃）Options 選項 任何 Pipo 色名 any Pipo token

Bar background color 整條背景色

Leave it empty for the default frosted-glass look (translucent white with blur). Set a Pipo token and the whole bar fills with that solid color — the blur is removed automatically. Pick a dark token like dunko or blornko and the logo, links, and icons auto-switch to white so they stay readable. Invalid tokens quietly fall back to frosted white.

留空就是預設的霧面玻璃（半透明白 + 模糊）。填一個 Pipo token，整條 bar 換成那個實色——模糊會自動移除。選深色 token（像 dunko、blornko），logo、連結、圖示會自動變白，維持清楚可讀。填了不存在的 token 會安靜退回霧面白。

<!-- 淺色實底 light solid -->
<pipo-navbar logo="Brand" bar-color="blonko"></pipo-navbar>

<!-- 深色實底 → 文字自動轉白 dark → white text -->
<pipo-navbar logo="Brand" bar-color="dunko"></pipo-navbar>
bar-color — dark bars flip text to white automatically · 深色 bar 自動白字
bar-color="" (預設霧面白)
bar-color="blonko" (淺色實底)
bar-color="dunko" (深色 → 自動白字)
bar-color="blornko" (深藍灰 → 白字)
links Default 預設 ""Options 選項 "Label:URL" 逗號分隔

Nav links 導覽連結

Comma-separated. Each item can be Label:URL or just Label (defaults to #). The current page's link gets highlighted automatically by matching href to the browser's pathname.

逗號分隔。每項可以是 Label:URL，也可以只寫 Label（會自動 fallback 到 #）。當前頁的連結會自動高亮——靠比對 href 與瀏覽器的 pathname 決定。

<!-- Label:URL 格式 -->
<pipo-navbar
  links="首頁:/,作品集:/portfolio,關於:/about"
></pipo-navbar>

<!-- 純 Label（href 自動 # ）-->
<pipo-navbar
  links="首頁,作品集,關於"
></pipo-navbar>
links — hover to see the highlight · 滑過看高亮
links="首頁:/,作品集:/portfolio,關於:/about"

CTA · 行動按鈕

One button that means business.

一顆讓人想按的行動按鈕。

cta Default 預設 ""（不顯示）Options 選項 任何字串 any string

CTA button text 行動按鈕文字

Fill in text and a CTA button appears at the right end of the bar. Leave it empty and nothing renders — no empty space, no placeholder. Add cta-href to make it a real link.

填入文字，bar 右側就出現一顆 CTA 按鈕。空白時什麼都不顯示，不佔空間。搭配 cta-href 讓它變成真正的連結。

<!-- 有 cta -->
<pipo-navbar cta="開始使用"></pipo-navbar>

<!-- 無 cta → 不渲染按鈕 -->
<pipo-navbar></pipo-navbar>
cta — with vs. without · 有 vs 無按鈕
cta="開始使用"
cta="" (空白 → 不渲染)
cta-color Default 預設 繼承 colorOptions 選項 任何 Pipo 色名

CTA button color 按鈕顏色

Override the button color independently from the nav accent. Useful when you want a standout call-to-action in a different tone. Falls back to color if the token doesn't exist.

讓按鈕顏色獨立於導覽強調色。想要 CTA 特別顯眼時很好用。填了不存在的 token 會退回繼承 color。

<pipo-navbar
  color="mibble"
  cta="聯繫我"
  cta-color="glorix"
></pipo-navbar>

pill gives a fully rounded capsule. rounded uses gentle 10px corners for a more structured look.

pill 是完全的圓角膠囊。rounded 是帶有柔和圓角的矩形，看起來更工整。

cta-anim Default 預設 "float"Options 選項 float / tilt

CTA hover animation 按鈕滑過動畫

Same two animations as pipo-button: float lifts the button up, tilt tips it sideways. Both press down with a springy squish.

和 pipo-button 相同的兩種動畫：float 往上浮起，tilt 往旁邊歪。按下去都會有彈簧感的壓扁。

<pipo-navbar cta="試試看" cta-anim="tilt"></pipo-navbar>
cta-anim — hover the CTA buttons! 滑過 CTA 按鈕試試看!
cta-anim="float"（預設）

cta-href · cta-target Default 預設 cta-href=""（是按鈕） / cta-target="_self"Options 選項 _self / _blank

Make CTA a link 讓 CTA 變連結

Add cta-href and the button becomes a real <a> link. Set cta-target="_blank" to open in a new tab — rel="noopener noreferrer" is added automatically.

加上 cta-href，按鈕就變成真的 <a> 連結。設 cta-target="_blank" 在新分頁開啟——rel="noopener noreferrer" 會自動補上。

<!-- 新分頁開啟 open in new tab -->
<pipo-navbar
  cta="官網"
  cta-href="https://example.com"
  cta-target="_blank"
></pipo-navbar>
cta-href
cta-href="" → <button>
cta-href="#" → <a> link
Socials · 社群連結

Seven platforms, one attribute.

七個平台，一個屬性。

socials Default 預設 ""（不顯示）Options 選項 "platform:URL" 逗號分隔

Social icon links 社群圖示連結

Comma-separated list of platform:URL. Each entry renders an SVG icon that links to your profile. Hover an icon and a little tooltip with the platform name pops up (pure CSS, not the browser's native title). Unknown platforms are silently ignored. All links open safely with rel="noopener noreferrer".

逗號分隔的 platform:URL 清單。每項渲染一個 SVG 圖示連結。滑過圖示會跳出顯示平台名稱的小 tooltip（純 CSS，不是瀏覽器原生的 title）。不認識的平台名靜默忽略，不報錯。所有連結自動補上安全的 rel。

Mobile · 手機響應式

Pure CSS hamburger menu.

純 CSS 漢堡選單，不需要 JavaScript。

On screens 720px and narrower, pipo-navbar hides the nav links, CTA, and social icons inside a dropdown. A hamburger button appears — click it to expand the menu. The animation uses --pipotoy-spring for that springy open feel. No JavaScript required.

螢幕寬度 720px 以下，pipo-navbar 把導覽連結、CTA 按鈕、社群圖示全收進下拉選單。漢堡按鈕出現——點一下展開。動畫使用 --pipotoy-spring，有彈簧感。不需要 JavaScript。

mobile — resize your browser below 720px to see the hamburger · 把瀏覽器縮窄到 720px 以下看漢堡按鈕

Good to Know · 備註

Small things worth knowing.

幾件值得知道的小事。

📌
It's always fixed at the top
The bar floats at the top of the viewport regardless of scroll position. You don't need to add any wrapper or CSS — that's the whole point.
pipo-navbar 永遠固定在視口頂部，不管頁面滾到哪裡。不需要任何包裝元素或 CSS——這就是它存在的意義。
✦
One token, three places
color sets the logo icon background, active link highlight, and the default CTA button color simultaneously. Use cta-color to override just the button.
color 同時設定 logo 圖示背景、當前連結高亮、CTA 預設顏色三個地方。用 cta-color 單獨覆寫按鈕顏色。
📱
Zero-JS hamburger
The mobile menu uses a CSS-only checkbox trick — no JavaScript event listeners. This means it works even if your JS fails to load.
手機選單用的是純 CSS checkbox 技巧，沒有 JavaScript 事件監聽器。即使 JS 掛掉，選單依然能用。
🌗
Dark bars flip text to white
When bar-color is a dark token, the component measures its luminance and automatically switches the logo, links, and icons to white — so you never end up with dark text on a dark bar.
當 bar-color 是深色 token 時，元件會量測它的亮度，自動把 logo、連結、圖示換成白色——你永遠不會遇到深色 bar 配深色字的窘境。
🛡️
All external links are safe
Any social icon link and any CTA with cta-target="_blank" automatically gets rel="noopener noreferrer" — you never have to remember it.
所有社群圖示連結，以及設了 cta-target="_blank" 的 CTA，都會自動補上 rel="noopener noreferrer"，你永遠不需要自己記。
